# 英語小鎮 專案規劃

這份文件記錄產品方向、已定案的決策、開發進度與待辦事項。任何 AI 開發工具（Claude Code、Codex）開始工作前請先讀這份文件；決策有變動時請同步更新。

最後更新：2026-10-27

## 一、產品定位

- 參考對象：App Store 上的 English Town: Vocab, Shadowing（越南 Nixtech 開發）。只參考玩法類型，畫面、角色、文案要做成自己的風格，不可照抄
- 用途：自用工具（自己與家人），不做登入、訂閱、廣告
- 每人各用一台裝置，不需要切換使用者
- 核心：口說情境對話為主，單字小遊戲為輔
- 差異化：網頁版（對方只有 App，使用者留言大量要求網頁版）、分級單字庫、自訂單字本
- 網址：https://zioszioszios-web.github.io/english-town-proto/

## 二、技術架構

- Vite + TypeScript + Phaser 3，部署到 GitHub Pages（推送 main 自動部署）
- Phaser 只負責小鎮地圖與角色；所有介面（選單、對話、小遊戲、搖桿）用 HTML + CSS，放在 src/ui/ 與 src/games/
- CSS 用相對單位，介面最大寬度 480px 置中
- 之後要支援電腦全螢幕：地圖改 Phaser RESIZE 模式，介面用 CSS 響應式改成側欄
- 之後可用 Capacitor 包成 iOS / Android App
- 資料存 localStorage（讀寫包 try/catch，存檔有版本號）
- 語音：NPC 與單字發音用 speechSynthesis（en-US，語速 0.9，iOS 需使用者點擊解鎖）

## 三、已定案的決策

### 操作
- 虛擬搖桿移動，電腦可用方向鍵 / WASD
- 靠近建築出現「進入」按鈕，不自動進入

### 等級
- Lv1 國中以下、Lv2 高中、Lv3 大學、Lv4 社會人士
- 開場選「從第一級破關」或「直接進入第四級」
- 破關模式：完成該級指定比例情境解鎖下一級（UNLOCK_RATIO，暫定 1.0）

### 地點
- 共用：咖啡廳、飯店、藥局、公園（釣魚）、街道（跑酷）
- 等級專屬：學校（Lv1、Lv2）、辦公室（Lv4）

### 劇本選項設計
- 選項分三種：branch（劇情分支）、variant（同義不同說法，附語氣說明）、mistake（錯誤選項，附 NPC 反應、正確說法、中文解說）
- Lv1、Lv2 以 branch + mistake 為主；Lv3、Lv4 以 branch + variant 為主
- 同一節點的選項不可只差一兩個單字
- 英文必須自然、符合母語者用法，不可直譯
- 節點只有一個正確選項時，該選項標為 branch（線性前進）；「branch 節點」指含 2 個以上 branch 選項的節點
- 每個節點只能是 branch 或 variant 其中一種，mistake 可加在任何節點
- 「不可只差一兩個單字」以單字層級編輯距離 ≥ 3 檢查（含 mistake 選項）
- 每條路徑 5～8 句（不含答錯）
- 學到的說法數量 = 走過的 variant 節點中所有說法 + 答錯時看到的正確說法（不重複計算）

### 單字庫
- Lv1：教育部國中小基本 2000 字
- Lv2：大考中心高中英文參考詞彙表（扣除 Lv1）
- Lv3：NAWL（扣除 Lv1、Lv2）
- Lv4：TSL 多益字表（扣除 Lv1~Lv3）
- NAWL、TSL 為 CC BY-SA 4.0，需標示出處
- 教育部、大考中心字表為公開資料但非開放授權，自用沒問題，若公開上架需再評估
- 只有 Lv4 可以新增自訂單字

### 小遊戲（依地點設計）
- 公園：釣魚（看英文選中文）
- 學校操場：拼字跑步（顯示中文、詞性、首尾字母提示，拼對前進一步）
- 飯店：翻牌配對
- 咖啡廳：聽單點餐
- 藥局：整理藥櫃（英文藥盒拖到對應中文櫃子）
- 辦公室：郵件填空
- 街道：選道路跑酷
- 計分與排行榜為主，獎勵之後再討論
- 排行榜先存本機（LocalScoreRepository），之後改接雲端讓家人互比

### 美術
- 先用色塊，玩法確定後再討論風格

### 開發節奏
- 每個階段都要實機測試後才進下一階段

## 五、待討論事項

## 六、下一個待執行任務：實機測試與單字抽查

依「每個階段都要實機測試後才進下一階段」，進入階段 4 前先完成：

1. 手機實機玩過 8 個情境，每個情境至少走兩種路線，確認錯誤回饋、語氣說明、完成畫面統計正常，劇本英文自然
2. 七個小遊戲實機測試
3. 抽查 data/review-list.md 列出的單字
4. 發現的問題修正後，再開始階段 4（語音辨識、跟讀、逐字評分）
